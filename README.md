# PlaceTrack – Smart Campus Placement Management System

<p align="center">
  A centralized platform to simplify campus placements,
  manage recruitment drives and track student applications.
</p>

---

## Overview

PlaceTrack is a campus placement management platform
designed to connect students and placement coordinators
through a centralized digital system.

The platform aims to simplify the placement process by
providing a structured environment for discovering
job opportunities, checking eligibility criteria,
applying for positions and tracking application progress.

## Problem Statement

Students often face difficulties tracking placement
opportunities, company eligibility requirements,
application deadlines and recruitment updates.

PlaceTrack aims to solve these problems through
a centralized and organized placement platform.

## Key Features

### Student Module

- Student registration and login
- Student profile management
- Browse placement opportunities
- View company eligibility criteria
- Apply for placement drives
- Track application status

### Placement Coordinator Module

- Manage company information
- Create recruitment drives
- Define eligibility criteria
- View student applications
- Update application progress
